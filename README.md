# Defesa Estratégica Premium

Crie uma landing page premium para advogado trabalhista empresarial, utilizando como inspiração visual o design fornecido (preto + dourado sofisticado), com foco em autoridade, elegância e conversão.

🎨 DESIGN (OBRIGATÓRIO)

Basear o layout no estilo do modelo enviado:

Fundo predominante: preto ou azul muito escuro

Elementos em dourado metálico (gradiente)

Tipografia elegante (estilo serifado para títulos grandes)

Visual luxuoso, minimalista e corporativo

Uso de:

barras douradas

cards com bordas finas

efeitos hover sofisticados

Animações:

fade-in ao rolar

leve zoom em imagens

transições suaves
